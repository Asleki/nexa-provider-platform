# NoveGeo World Boundary Dataset

This governed source family supports P004.1 and P004.2.

- `raw/` preserves the received candidate unchanged.
- `candidate/` contains the reviewable candidate.
- `qualified/` contains the normalized MultiPolygon representation.
- `publication/` contains the public-safe representation.
- `quarantine/` is reserved for rejected candidates and receipts.

The authoritative database form is installed only through the approved migration-control system.
